# SharedItems

The group part of a trip: the shared items list with who's bringing what, and everyone's packing progress.

**Provide:** shared items with their claimer (or none), and each member's initial and percentage.

- Unclaimed items show a dashed "I'll bring it" button; claimed ones show the person in handwriting: "Mia's got it", or "you".
- Friends only ever see percentages here, never each other's personal items or quantities.
