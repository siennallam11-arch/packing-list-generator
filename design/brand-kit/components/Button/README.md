# Button

Buttons in typewriter bold: one filled ink button per screen for the main action, a dashed quiet button for secondary actions, and a dotted-underline text button for skipping.

**Provide:** a label that says exactly what happens ("Pack my bag", "+ add another city", "Skip").

- Filled: `ink` background, `on-ink` text, `radius-sm`. One per screen.
- Quiet: dashed `ink-soft` outline, `ink` text. For adding things.
- Text: no box, dotted underline. For Skip and Cancel.
- Disabled: 40% opacity, and say why nearby.
