# Doodle

Hand-drawn icons for categories, weather and group trips: a wobbly ink outline over a soft, slightly off-register fill.

**Provide:** a doodle name and, optionally, a fill token as `--df`.

- Ink follows `currentColor` (so `ink` in both themes); the fill defaults to the doodle's own pastel (`fill-pink`, `fill-green`, `fill-blue`, `fill-butter`, `fill-tan`).
- Sizes: 26px beside a city, 28–36px beside a heading, 46px in the cover badge, 64px+ on empty states. Never below 24px: the wobble turns to noise.
- One doodle per heading or row. Don't line them up as decoration.
- Uploaded SVGs in **Assets → Doodles** have the ink fixed at `#222020`; use them only on light grounds. In the app, draw them inline so the ink can follow the theme.
