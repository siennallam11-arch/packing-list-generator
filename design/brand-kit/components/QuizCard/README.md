# QuizCard

One quiz question per card, answered with one tap; every question can be skipped.

**Provide:** the question, 2–4 options, the step ("Question 1 of 7") and the previous answer if there is one.

- Question in `hand-heading` with a doodle; options in typewriter on dashed outlines. The selected option gets a solid `ink` outline on `selected`.
- Answers carry over from your last trip; show them already selected.
- Copy is casual and short: "Do you overpack?", "Fancy dinner?", "Laundry where you're staying?"
