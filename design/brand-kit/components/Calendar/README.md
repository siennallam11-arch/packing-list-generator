# Calendar

A simple month calendar for picking one city's dates: tap the start day, then the end day.

**Provide:** the month, the selected start and end, and the city it's for.

- Start and end are `ink` discs; the days between sit on `selected`.
- The footer repeats the choice in words: "Tokyo · Dec 10 – Dec 13 · 3 nights".
- Each city gets its own range; the next city's calendar opens on the previous city's end date.
