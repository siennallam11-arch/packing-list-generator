# Doodles

The Caboodle doodle set as standalone SVGs, 48-unit grid, ink `#222020` with each doodle's own pastel fill. For light grounds only; in the app, draw doodles inline so the ink follows the theme. Category: passport (documents), sock (clothes), toothbrush (toiletries), plug (tech), backpack (activity gear), bottle (odds & ends). Weather: umbrella, snow, sun. Trip: suitcase. Group: people.
